## 已确认焊点

| 焊点 | 信号 | → USB-TTL |
|------|------|-----------|
| **TP7308** | DEBUG_UART_TX（GPIO34） | RX |
| **TP7307** | DEBUG_UART_RX（GPIO35） | TX |
| GND | 同区 TP7302/7303 或 USB 壳 | GND |

电平 **1.8V** · 波特率 **115200 8N1**

## 易搜错

| 不是 | 说明 |
|------|------|
| U7208 GP0/GP1、R72xx | 无线充电 |
| HST_WLAN_UART_* | WiFi UART |
| R5604、TP1311、R6000 | 电源/摄像头/屏幕区 |
| 搜 TX/RX 太宽 | 射频、外设 UART 混杂 |
| elish 11 寸图纸 | 板型不同 |

## 软件侧

- UART12 / `qup_uart@a90000` / GPIO34+35
- 主线：`console=ttyMSM0,115200n8`
- UEFI `@988000` 为固件配置，**非飞线焊点**
