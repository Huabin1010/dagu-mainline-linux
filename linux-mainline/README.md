# dagu 主线 Linux

对照 [ginkgo-mainline-linux](https://github.com/Huabin1010/ginkgo-mainline-linux)（ginkgo / Linux 7.0），以及 11" Pad 5 Pro（**elish**）的 postmarketOS 主线：[docs/elish-pmos-vs-dagu.md](docs/elish-pmos-vs-dagu.md)。他们在原厂 v3 上刷的自造 boot 格式：[docs/elish-pmos-boot-format.md](docs/elish-pmos-boot-format.md)。ABL 为何收这份镜像：[docs/elish-abl-legacy-boot-path.md](docs/elish-abl-legacy-boot-path.md)。设备：**小米平板 5 Pro 12.4**（`dagu` / SM8250）。

内核源码和 `out/` **不入库**。blob 用 `./scripts/stage-firmware.sh` 从 `dumps/` 解开。

刷写 / ABL / ramdisk 实验记录（2026-08-30，P0 未通）：[docs/dagu-fastboot-abl-ramdisk.md](docs/dagu-fastboot-abl-ramdisk.md)。ABL 是什么、和 LK / ginkgo 的差别：[docs/abl-vs-lk.md](docs/abl-vs-lk.md)。**刷机指南**：[docs/flash-guide.md](../docs/flash-guide.md) / [简体中文](../docs/zh-CN/flash-guide.md)。**外设适配总表**：[docs/dagu-adaptation-status.md](docs/dagu-adaptation-status.md)。Wi‑Fi 866 PHY、Adreno/GMU、Turnip dEQP、CPU 调频与 stress-ng：[docs/dagu-wifi-gpu-turnip-cpu.md](docs/dagu-wifi-gpu-turnip-cpu.md)。

## 铁律

- **不要用 Google platform-tools 37 的 `fastboot`。** 刷写走 `scripts/fb-usb.py` / `./scripts/flash-boot.sh`，**双槽都写**。这台 ABL 不接受「只 `fastboot boot`」。
- **不要刷空 DTBO**（`dtbo-empty.img`，`dt_entry_count=0`）。默认用 `dtbo-stub.img`。机制见 [docs/dagu-dtbo-abl.md](docs/dagu-dtbo-abl.md)。
- **只要 Ubuntu，不要安卓。** rootfs 刷到 **userdata**（无 A/B，一块盘），覆盖 `/data`。不另建 `linux` 分区，不写 `super`。
- dagu 是 **A/B**。`boot`/`dtbo`/`vendor_boot` 有 `_a` `_b`；userdata 没有。
- 不要把 CAF 四份 DTB concat、不要把活机 FDT 当 vendor_boot、不要改 `&usb_1` 为 `qcom,snps-dwc3` combined。
- 面板是 **L81A dual-DPHY**，不是 elish 的 NT36523 CPHY。
- Wi‑Fi BDF 用 `bd_l81a.elf` → `board.bin`。单机 persist MAC 写在 gitignored `dts/local-addresses.dtsi`，不要提交。

| 阶段 | 内容 | 验收 |

## 主机 USB（AMD 这台）

Google `fastboot` 37 在这台 Ryzen 上会卡在 `USBDEVFS_REAPURB`（`fwupd` 还把 `18d1:d00d` 认成 Quectel 猫）。`fastboot devices` 只读描述符所以看起来正常。刷写走 `scripts/fb-usb.py`（独占 libusb），不要用 `flash -S`。

```bash
./scripts/flash-boot.sh flash    # 或 restore
# 可选加固：sudo ./scripts/host-usb-fix.sh
```

## 编译

```bash
cd linux-mainline
./scripts/setup-deps.sh
./scripts/setup-kernel.sh
./scripts/stage-firmware.sh
./scripts/build-kernel.sh
./scripts/build-bootimg.sh
./scripts/build-rootfs.sh
./scripts/build-rootfs-image.sh
./scripts/flash-rootfs.sh          # 写 userdata，清空安卓
./scripts/boot-fastboot.sh         # 只 RAM 加载内核，不写 boot
./scripts/usb-connect.sh
./scripts/ssh-run.sh dmesg
# SSH key is linux-mainline/out/id_dagu (generated by build-initramfs.sh, gitignored)
# Ubuntu root 密码：构建时 ROOT_PASSWORD=... 或 linux-mainline/out/root-password（不入库）
```

空 DTBO（`count=0`）已证明会 6 秒回 fastboot，不要当排查手段。对照/恢复：`./scripts/make-empty-dtbo.sh restore`。说明：[docs/dagu-dtbo-abl.md](docs/dagu-dtbo-abl.md)。

## 不会变砖 / A/B

刷 Ubuntu **不会**毁掉启动链：

| 分区 | 是否 A/B | 我们写不写 | 后果 |
|------|----------|------------|------|
| `boot_a` / `boot_b` | 是 | **不写**，只 `fastboot boot` | 两边原厂内核都在 |
| `dtbo_*` / `vendor_boot_*` / `vbmeta_*` | 是 | 默认不写；空 DTBO 只动当前 slot | 另一边仍是原厂 |
| `super`（里面才是 system_a/b） | 逻辑槽 | **不写** | 原厂 system 还在 super 里 |
| `userdata` | **否**，整机一份 | 刷 Ubuntu | 安卓 `/data` 没了 |
| `xbl` / `abl` | 是 | **不写** | 永远能进 fastboot / EDL |

救砖：音量下+电源进 fastboot，或 9008 EDL 刷官方 `flash_all`（**不要 lock**）。见 [dagu EDL 救砖](../docs/dagu-edl-recovery-full-playbook.md)。

刷完 userdata 后 **不要** `fastboot reboot`：ABL 会加载当前 slot 的安卓 `boot`，挂不上 Ubuntu 的 ext4。要用 `./scripts/boot-fastboot.sh`。

活机 dump：`current-slot:a`，`slot-successful:a:yes`。

## Ubuntu（userdata）

本机只跑 Ubuntu。`out/rootfs.ext4` 刷进 **userdata**（约 228 GiB，不是 A/B），开机后 `dagu-resize-root` 会把 4 G 镜像扩到整盘。

```bash
./scripts/build-rootfs.sh
./scripts/build-rootfs-image.sh
./scripts/flash-rootfs.sh
# 等价：fastboot flash userdata out/rootfs.ext4
```

initramfs 按 GPT 名 `userdata`（回退 `/dev/sda34`）挂 ext4，再 `switch_root`。还没刷过、或仍是安卓 f2fs 时，留在 ramdisk + RNDIS。
