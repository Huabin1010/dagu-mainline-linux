# dagu 主线 Linux

对照 `~/Projects/Kernel-Build`（ginkgo / Linux 7.0）。设备：**小米平板 5 Pro 12.4**（`dagu` / SM8250）。

内核源码和 `out/` **不入库**。blob 用 `./scripts/stage-firmware.sh` 从 `dumps/` 解开。

## 铁律

- 只 `fastboot boot`，禁止 `fastboot flash boot`。
- **禁止** mount / 格式化 Android **userdata**。Ubuntu 只允许刷到独立分区。
- 不要把 CAF DTB/DTBO 叠到主线；boot.img 是 header v2 + 镜像内 DTB。
- 面板是 **L81A dual-DPHY**，不是 elish 的 NT36523 CPHY。
- Wi‑Fi BDF 用 `bd_l81a.elf` → `board.bin`，厂 MAC persist `F0:6C:5D:71:3A:2B`。

## 阶段

| 阶段 | 内容 | 验收 |
|------|------|------|
| P0 | ramdisk + RNDIS `192.168.7.2` + dropbear/minish | `./scripts/boot-fastboot.sh` 后 `./scripts/usb-connect.sh` |
| P1 | UFS 枚举；rootfs **不是** userdata | `ls /dev/sda*`；见下方分区 |
| P2 | `ARM_QCOM_CPUFREQ_HW` + TSENS | `/sys/devices/system/cpu/cpu0/cpufreq` |
| P3 | L81A panel 驱动 + DPHY | fbcon / DRM，DCS 0x0A |
| P4 | Himax SPI IRQ39 RST100 | `evtest` |
| P5 | pcie0 + ath11k + `htbtfw20.tlv` | `wlan0` 扫描 |
| P6 | 双 BQ27Z561 5000 mAh | `power_supply` |
| P7 | CS35L41 节点 + ADSP 路径 | 能 probe；`speaker-test` 后置 |
| P8 | 本机 a650 zap + Turnip；Ubuntu 独立分区 | `out/rootfs.ext4` **禁止** `flash userdata` |

## 编译

```bash
cd linux-mainline
./scripts/setup-deps.sh
./scripts/setup-kernel.sh
./scripts/stage-firmware.sh
./scripts/build-kernel.sh
./scripts/build-bootimg.sh
./scripts/boot-fastboot.sh
./scripts/usb-connect.sh
./scripts/ssh-run.sh dmesg
# SSH key is linux-mainline/out/id_dagu (generated by build-initramfs.sh)
```

立刻弹回 fastboot 才考虑空 DTBO（`make-empty-dtbo.sh`），用完恢复 `dumps/dagu-20260826-210700-root/images/dtbo_a.img`。

## 独立 Linux 分区（P1 / P8）

不要动 userdata。候选：shrink userdata 后新建 `linux`，或闲置 OEM 分区（刷之前 `fastboot getvar all` 再定名）。

```bash
./scripts/build-rootfs.sh
./scripts/build-rootfs-image.sh
# 例：fastboot flash linux out/rootfs.ext4
# 不要：fastboot flash userdata out/rootfs.ext4
```
