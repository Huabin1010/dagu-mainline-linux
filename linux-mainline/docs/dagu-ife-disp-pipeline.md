# 前后摄像头硬件通路：图像前端 1 像素通路 → NV12（NV12 semi-planar 4:2:0，亮度平面加交织色度平面的 4:2:0 格式）→ 应用

记录日期：2026-10-24。内核 `#629`。设备：dagu，Linux 板 `ab22268c`，只用 B 槽。

## 1. 现在的数据流

```text
传感器（前 imx596 / 后 s5kjn1）
  → 相机串行接口物理层 4 / 1 → 相机串行接口解码器 1 的像素口
  → 图像前端 1：相机接口 → 黑电平+降噪 → 去马赛克（含白平衡增益）
     → 色彩校正矩阵 → 伽马 → 色彩空间变换 → 缩放器 → 圆整钳位 → 写通道 4/5
  → 线性 NV12 1280×960（传感器原始比例，全视场缩小）
  → dagu-camera-loopback（打包 + 自动曝光 + 自动白平衡）
  → v4l2loopback /dev/video20（前）/ /dev/video21（后），YUYV 1280×720
  → 应用（PipeWire、Snapshot、会议软件）
```

（上面代码块里的 NV12、YUYV 是格式名：NV12（NV12 semi-planar 4:2:0，亮度平面加交织色度平面的 4:2:0 格式），YUYV（packed luma-chroma 4:2:2，打包的 4:2:2 亮度色度格式）。）

处理器上不再做去马赛克。生产者只做两件事：把 NV12（NV12 semi-planar 4:2:0，亮度平面加交织色度平面的 4:2:0 格式）交织成 YUYV（packed luma-chroma 4:2:2，打包的 4:2:2 亮度色度格式），取中间 16:9 一带并按原来的方向翻转；以及每两帧跑一次自动曝光和白平衡。单核占用约 23%，每秒 30 帧。

图像前端硬件通路起不来时（比如没有这个内核），生产者会退回软件图像信号处理器。设环境变量 `DAGU_CAMERA_SOFTISP=1` 可以强制退回。

## 2. 用传感器测试图测出来的寄存器含义

方法：通过 I²C（Inter-Integrated Circuit，芯片间总线）直接写传感器测试图寄存器 `0x0600`（彩条 = 2，纯色 = 1；纯色电平在 `0x0602`–`0x0608`），再用驱动的运行时程序接口逐项改寄存器，量 NV12（NV12 semi-planar 4:2:0，亮度平面加交织色度平面的 4:2:0 格式）输出。驱动里测试图控件那条路的写入在 imx596 上不生效。

下表里“定点 n”指小数部分占 n 位的定点数，例如定点 10 时 `0x400` = 1.0。

| 块 | 偏移 | 含义 |
|---|---|---|
| 相机接口 | `0x2660` 位 24–26 | 图像前端看到的拜耳顺序。前置彩条要红绿绿蓝排列（值 0）才对，传感器报的却是 SBGGR10（Sequential Blue-Green-Green-Red 10-bit，蓝绿绿红 10 位原始格式）；后置用绿蓝红绿排列（值 3），和传感器报的一致 |
| 解复用 | `0x3094`–`0x30a0` | 每通道整数增益（每字节一个）。`0x04` 把 10 位传感器数据推到伽马要的 12 位域 |
| `0x3400`（模块配置字 `0xc101`） | 三张查找表 + 46 个配置字 | 去黑电平并做拜耳降噪。关掉时，传感器黑（码值 64）会落在 sRGB（standard Red Green Blue，标准红绿蓝色彩空间）约 70，整幅发灰；打开后约 9 |
| 镜头阴影校正 `0x3600` | 查找表 1、2，各 221 项（17×13） | 每项：高 13 位 = 绿通道，低 13 位 = 红或蓝通道，定点 10 |
| 去马赛克 `0x3800` | `0x3868` = 蓝<<16 \| 绿，`0x386c` = 红 | 白平衡增益，定点 10 |
| 色彩校正 `0x3a00` | `0x3a68` 起 9 个字 | 按输入通道绿、蓝、红排行；每行 字0 = 输出绿（低半字）\| 输出蓝（高半字），字1 = 输出红；定点 7 |
| 伽马 `0x3e00` | 查找表 1–3，各 64 项 | 项 = 增量<<10 \| 基值；按 12 位输入分 64 段（索引 = 输入>>6）；**值按 8 位输出单位存**，值会原样进 NV12（NV12 semi-planar 4:2:0，亮度平面加交织色度平面的 4:2:0 格式）亮度 |
| 色彩空间变换 `0x4068` 起 | 3 行 × 4 字 | 输入绿、蓝、红；亮度系数定点 10，两路色差系数定点 12（13 位有符号）；字2 = 偏移<<16 |
| 缩放器 `0x4c00`（亮度）/ `0x4e00`（色度） | `+0x64` = `0x600`，`+0x68` = 输入尺寸，`+0x6c` 水平相位，`+0x74` 垂直相位 | 相位 = 定点 21 \| `0xc0000000`；色度相位是亮度的两倍；其余字写 0。`+0x64` 写 0 时水平缩放会坏 |
| 圆整钳位 `0x5000` / `0x5200` | `+0x68` 行数-1，`+0x6c` 宽-1 | 显示通路的最后一级 |
| 查找表写入口（每个块） | `+0x08` 地址，`+0x0c` 表选择，`+0x14` 数据 | 先写表选择，地址清 0，再连续写数据 |
| `0x4400`/`0x4600`/`0x4800`/`0x4a00` | 人脸检测支路 | 必须关 |
| `0x5800`/`0x5a00`、`0x5408`/`0x5608`/`0x5c08`/`0x5e08` | 缩小通路 | 线性通路不用，关掉 |

验证结果：

- 前后两个摄像头都输出标准的 BT.601（Broadcasting Television Recommendation 601，国际电联标清视频色彩标准）彩条：白 255，黄 226，青 179，绿 150，品红 105，红 76，蓝 29，黑 0。
- 纯色电平扫描与 sRGB（standard Red Green Blue，标准红绿蓝色彩空间）理论值相差 1–4 个码值。

## 3. 驱动（`camss-vfe-480.c`）

- `vfe_480_disp_program()`：每次开流按格式重写整条显示通路，通路外的块全部关掉。上一次流留下的寄存器不会再带进下一次。旧路径保留，`dagu_disp_new=0` 可以切回去。
- 宽高比：按输出比例居中裁剪相机接口窗口。生产者要的是 1280×960，和传感器同比例，所以基本不裁剪，镜头阴影网格按全幅对齐。
- 默认画质：sRGB（standard Red Green Blue，标准红绿蓝色彩空间）伽马、全范围 BT.601（Broadcasting Television Recommendation 601，国际电联标清视频色彩标准）、黑电平+降噪、单位矩阵色彩校正、默认白平衡。没有用户态程序时也能直接出正常彩条。
- `/sys/kernel/debug/dagu_ife1/`：
  - `prog_front`、`prog_rear`：开流时加载的程序，以 `@sof` 开头的行每个帧起始都执行一次。
  - `live`：下一个帧起始执行一次，随后的寄存器更新时生效。
  - `dmird`：查找表读回。目前读不出数据，只留着备用。
  - 程序行格式：`w 偏移 值`，或 `dmi 基址 表 值…`。只允许写 `0x2c` 和 `0x2000`–`0x9ffc`。
  - 往这些文件写空程序要写 `# empty`；用 `: >` 截断不会调用写入函数，旧程序会留着。
- 飞行记录器：`dagu_fr_us`（默认 0，即关闭）、`dagu_fr_ms`。

## 4. 生产者（`camera-loopback/cpp/dagu_hw.cpp`）

- 媒体图：先复位所有链接，再接相机串行接口物理层的源口到 `msm_csid1:0`，`msm_csid1:4 → msm_vfe1_pix:0`。各口设传感器格式，像素口合成尺寸设 1280×960。
- 画质程序：
  - 色彩校正矩阵用一组通用的饱和度恢复矩阵，每行之和为 1。
  - 色彩空间变换用 BT.601（Broadcasting Television Recommendation 601，国际电联标清视频色彩标准）有限范围，符合 YUYV（packed luma-chroma 4:2:2，打包的 4:2:2 亮度色度格式）摄像头的约定。
  - 色调曲线：sRGB（standard Red Green Blue，标准红绿蓝色彩空间）加少量黑位裁切和轻微 S 形。
  - 前置镜头阴影校正只用亮度部分：绿通道那一半网格用到所有通道，数据取自这台平板 HyperOS 里抓到的网格。
- 自动曝光：
  - 中心加权亮度，目标 110（有限范围）。高光过多时目标降到 95。
  - 在对数域阻尼调节，并有不调的死区。
  - 先加曝光时间。超过 10 毫秒后按 10 毫秒取整，避开 50 赫兹灯光闪烁。
  - 再加模拟增益：前置连续可调（索尼公式），后置只能取整数倍。
  - 最后用图像前端的数字增益补，最多 4 倍。
- 自动白平衡：
  - 在线性化后的红绿蓝值上做灰世界估计，剔除接近饱和、过暗和高饱和度的像素。
  - 每次只走 25%，增益限制在 1.0–3.2。
- 环境变量：`DAGU_HW_NOLSC=1` 关镜头阴影校正，`DAGU_HW_LSC_COLOR=1` 试用红蓝两半，`DAGU_HW_LSC_NOSWAP=1` 不交换红蓝两半。

- **色彩校正矩阵没有用色卡标定。** 现在是通用矩阵。
