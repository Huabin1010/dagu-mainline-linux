# Sensor hardware configuration

Source: [https://docs.qualcomm.com/doc/80-88500-1/topic/62_Sensor_hardware_configuration.html](https://docs.qualcomm.com/doc/80-88500-1/topic/62_Sensor_hardware_configuration.html)

The hardware configuration of the camera sensor module is available in the kernel DTSI
      files.

For more details about how to customize camera DTSI, see `kernel/msm-5.4/Documentation/devicetree/bindings/media/camera/`.

Note: The serial peripheral interface (SPI) is not supported for sensor configuration. It only supports the EEPROM driver.
